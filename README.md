# Nabdh Tech

A data analysis project examining women's participation in Saudi Arabia's ICT sector using official government data, benchmarked against Vision 2030 targets and ITU global standards.


## What This Project Does

Transforms raw government datasets into an interactive analytical dashboard that visualizes the trajectory of women's participation in Saudi ICT from 2020 to 2024, highlighting the gap between rising participation rates and absolute workforce representation.



```

## Data Sources

Saudi Open Data Platform (open.data.gov.sa)
Vision 2030 Official Documentation (vision2030.gov.sa)
International Telecommunication Union (ITU Digital Trends 2024)

All government data is used under the Saudi Open Data License (CC BY 4.0).

## Tech Stack

Python, Pandas, Matplotlib, Chart.js, HTML, CSS, JavaScript
